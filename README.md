# Amizax Frontend

Frontend application for a cryptocurrency exchange platform built with Vue.js.

## Overview

Amizax Frontend provides the user interface for managing accounts, wallets, transactions, and cryptocurrency exchange operations.

The application communicates with the Amizax backend API and delivers a responsive user experience for exchange-related activities.

## Features

- User authentication interface
- Wallet management dashboard
- Cryptocurrency exchange interface
- Transaction history
- User profile management
- Responsive design
- REST API integration
- Administrative views

## Tech Stack

### Frontend

- Vue.js
- JavaScript
- Axios
